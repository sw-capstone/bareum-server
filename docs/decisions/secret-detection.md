# 민감정보 탐지 기준

기존 대입문 정규식은 테스트의 메서드 호출을 비밀번호로 오탐해 CI를 막았다. Gitleaks로 교체하고 탐지와 CI 차단 판단을 분리한다.

- GitHub classic·fine-grained 토큰 형식과 개인키 규칙은 차단한다.
- 사용할 클라우드가 미정이므로 AWS·GCP 규칙은 차단 목록에서 제외한다. 기본 탐지 결과는 경고로 남긴다.
- 일반 비밀번호·API 키와 미검토 규칙은 경고로 남긴다. 실제 비밀값도 경고에 포함될 수 있으므로 담당자가 확인한다.
- 테스트 폴더 전체를 예외로 두지 않는다. 명시적인 예시값과 비밀번호 해시 대입 패턴만 좁게 제외한다.
- PR 중간 커밋과 전체 Git 이력을 검사한다. 도구 실행 실패는 통과시키지 않는다.
- 탐지값과 원문을 로그·artifact에 남기지 않는다.

차단 범위를 늘릴 때는 정상·실패 사례를 보완하고 PR에서 검토한다. 이 정책은 사용자가 승인한 경고 분리 방식을 반영한다.
