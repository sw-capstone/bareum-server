# 문서 지도

- `product/`: 서비스 범위와 수용 기준 요약
- `architecture/`: 레포 구조·영역 경계·백엔드 아키텍처·인프라·개발 컨벤션
- `harness/`: 개발 과정·제품 AI 하네스 설계. 최신 문서는 [`harness-v1.2.md`](harness/harness-v1.2.md)
- `harness/harness-file-roadmap.md`: 구현 단계별 하네스 파일 추가 순서와 완료 조건
- `experiments/`: RMA·CBR·하네스 비교 실험
- `decisions/`: 확정 결정과 재검토 조건
- `guide/development-guide.md`: 브랜치·코드 작성·검사·PR·병합 전체 개발 가이드
- `guide/harness-discussion-questions.md`: 하네스 운영·권한·검증·평가 논의 질문지
- `runbooks/local-harness.md`: 하네스 실행과 실패 대응

`product/planning-final-v1.1.md`는 GitHub에서 관리하는 기획 기준본이고, `product/service-spec.md`는 그 기준본에서 파생한 구현 요약이다. `product/README.md`에 갱신 규칙과 출처를 기록한다.

기획문서와 최신 참고 원천을 우선하며 미결 사항은 코드에서 확정하지 않는다.
