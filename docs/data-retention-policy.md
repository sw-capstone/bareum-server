# 바름 MVP 데이터 보관 및 파기 정책

보고서 업로드 파일, 분석 기록과 결과, 장애 확인용 로그에 적용한다.

## 보관 기준

| 대상 | 보유기간 | 적용 기준 |
| --- | --- | --- |
| 사용자가 다시 열 수 있는 분석 기록과 관련 데이터 | 사용자가 분석 기록을 삭제하거나 회원 탈퇴할 때까지 | 업로드 원본, 뷰어용 PDF, 파싱 본문, 검사 결과와 생성된 결과 리포트를 함께 보관한다. |
| 검사 실패 또는 분석 취소 후 재분석에 필요한 원본, 변환 PDF, 파싱 본문 | 해당 분석 종료 후 24시간 | 보유기간 안에 재분석을 시작하면 해당 분석이 끝날 때까지 보관한다. 같은 파일을 사용하는 다른 조회 가능한 분석 기록이 있으면 그 기록의 보관 기준을 적용한다. |
| 장애 확인용 로그 | 장애 발생일로부터 30일 | 실패 시각, 실패 단계, 오류 코드 등 장애 진단에 필요한 최소 정보만 남긴다. 원문, 파일명, 이슈에 인용된 문장은 로그에서 제외한다. |

24시간과 30일은 재분석 기회와 장애 대응을 위해 바름에서 정한 보유기간이다.

## 삭제와 파기

- 사용자가 분석 기록을 삭제하거나 회원 탈퇴하면 해당 기록의 조회를 차단하고, 보관 근거가 끝난 데이터를 지체 없이 파기한다.
- 소프트 삭제는 조회를 차단하는 데 사용한다. 파기 대상은 S3에 저장된 원본과 변환 PDF, DB에 저장된 파싱 본문과 분석 결과 등 해당 개인정보가 남아 있는 데이터다. 복원할 수 없는 방식으로 파기한다.
- 파일별 DB 소프트 삭제 시각과 실제 S3 삭제 완료 시각을 각각 기록한다.
- 다른 법령에 따라 보존해야 하는 개인정보는 법령이 정한 기간 동안 다른 개인정보와 분리해서 보존한다.

## 개인정보 처리방침 및 운영자 접속기록

- 개인정보 처리방침에는 처리 목적, 보유기간, 파기 절차와 방법을 공개한다. 법령에 따른 별도 보존이 필요한 경우에는 보존 근거와 항목도 명시한다.
- 운영자 등이 개인정보처리시스템에 접속한 기록은 1년 이상 보관한다. 고시 제8조의 2년 보관 요건에 해당하면 2년 이상 보관한다.
