# 하네스 문서

하네스의 최신 구조와 책임 경계는 [`harness-v1.4.md`](./harness-v1.4.md)에 정의한다.
구현 진행에 따라 추가할 검사 파일의 작업별 기준은 [`harness-file-roadmap.md`](./harness-file-roadmap.md)를 따른다.

저장소는 다음 순서로 운영한다.

1. 기획·회의 자료와 관련 결정 기록을 확인한다.
2. 계약·규칙·평가 자산이 확정되면 해당 경로에서 관리하고 관련 검사를 연결한다.
3. 웹은 서버 공개 API만 소비한다. AI는 `bareum-server-ai`에서 관리하며, 실행 경로와 배포 단위는 관련 아키텍처가 확정된 뒤 각 저장소에 반영한다.
4. 프롬프트는 확정된 뒤 버전 자산으로 관리한다. 제품 규칙·기준 데이터·평가 자산은 범위와 형식이 확정된 뒤 위치를 결정한다.
5. 서버는 하네스 검사와 자체 테스트, 웹은 `npm run check` 결과를 확인한다. 일반 작업의 로컬 실행은 선택 사항이다. AI는 해당 저장소의 하네스 검사와 자체 테스트 결과를 확인한다.

서버 하네스는 AI 저장소를 검사하지 않는다. AI 검사와 평가 코드는 `bareum-server-ai`에서 관리한다.

하네스 검사는 저장소 구조와 문서·계약 무결성을 정책에 정의된 범위에서 확인한다. 제품 품질과 모델 성능은 별도 평가셋과 사람 검토로 판단한다.
