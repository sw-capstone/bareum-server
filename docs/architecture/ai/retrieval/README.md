# 근거 검색

승인된 기준 데이터가 선택된 경우 `data/reference/`를 검색하고, 서비스 명세가 허용한 경우 승인된 법령 원문 API로 후보를 동적으로 확장한다. 기준 데이터와 외부 후보를 구분하여 출처·시행일·검색 시점·기준일을 trace에 남긴다.

검색 후보가 있다는 사실만으로 근거가 판정을 뒷받침한다고 보지 않는다. 조문 실재 검사와 적용성·근거 도출 검사를 통과하지 못하면 판단보류 또는 비노출 처리한다.

기준 데이터가 선택되지 않은 상태와 검색 실패, 후보 없음은 서로 구분한다. 외부 API 장애는 `RETRIEVAL_EXTERNAL_SOURCE_FAILED`, 적합 후보가 없는 경우는 `RETRIEVAL_NO_CANDIDATE`로 기록한다.
