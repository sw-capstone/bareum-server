# 파서

HWPX·DOCX·텍스트 PDF·직접 입력을 문단·문장·표로 구조화하고 원본 위치 ID를 보존한다. 스캔 이미지 문서는 현재 지원 범위에서 제외하며, 표·페이지·문단을 일부만 복원한 경우 `partial` 상태를 남긴다.

표준 출력의 필드와 위치 정보는 `packages/contracts/`의 Schema로 관리한다. 파서는 `source_text`, 정규화된 텍스트, 위치와 파싱 상태를 보존하고 Schema에 맞는 결과를 반환한다.

파서 상태는 `parsed`, `partial`, `unsupported`, `failed`를 구분한다. 파싱 실패나 지원하지 않는 형식을 전체 성공으로 표시하지 않으며, 후속 검사를 실행할 수 없는 경우 사유 코드와 함께 해당 축을 `SKIPPED` 또는 `WITHHELD`로 보낸다.

`indent_ta`처럼 의미가 불명확한 필드는 계약에 추가하기 전에 이름과 의미를 결정한다.
