# 아키텍처 문서

- [`repository-boundaries.md`](repository-boundaries.md): 저장소 간 책임과 의존 방향
- [`repository-structure.md`](repository-structure.md): 현재 확정된 저장소 구조

프로젝트는 `bareum-web`, `bareum-server`, `bareum-server-ai` 세 독립 Git 저장소로 운영한다. 백엔드와 AI의 모듈·코드 경로·실행 단위·배포 방식은 관련 결정이 완료되면 구현과 함께 추가한다.

구체 구현은 각 저장소의 `AGENTS.md`, 계약, 결정 기록과 하네스 기준 문서를 함께 따른다.
