# Backend

익명 세션, 업로드 경계, 분석 작업, 상태 조회, 영속성과 공개 API를 담당한다.

- `api/`: 공개 요청·응답 계약과 HTTP 경계
- `jobs/`: 분석 작업 생성·멱등성·상태 오케스트레이션
- `storage/`: 업로드 원문·결과·삭제 경계

AI 내부 구현과 모델 SDK를 API 계층에 노출하지 않는다. 큐·워커·인증·구체 저장소는 결정된 뒤 각 하위 영역에 추가한다.

## 하네스 연결

백엔드 변경은 공개 API와 계약, 세션·작업·상태·영속성 경계를 먼저 확인하고 하네스 결과를 PR 증거로 남긴다. 실제 구현 명령이 연결되면 다음 검사를 추가한다.

- 포맷
- 린트
- 타입
- 단위 테스트
- API 테스트
- DB·마이그레이션 테스트

실행 명령은 `scripts/`와 CI에 연결하고, 연결된 검사 결과와 실패 사례를 PR에 기록한다.
